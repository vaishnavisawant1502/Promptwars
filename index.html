Assumptions (tap to expand)

1. Loss Calculation Formula

$\text{Estimated Loss (L)} = \int_{t_0}^{t_1} (\text{Flow}_{\text{observed}} - \text{Baseline}_{\text{nominal}}) \, dt$. Flow (L/min) × duration (min) = Litres; each simulation tick represents 1 simulated minute. Only the net excess above expected operational baseline is tallied, as an estimate from simulated data. Water utilized during normal operational cycles is excluded.

2. Heuristic Rules vs. Machine Learning

This prototype uses deterministic heuristic rule evaluations (e.g., duration-checked baseline excursions and flat-line variance filters) designed for transparency and immediate facility action. It does not employ black-box ML.

3. Simulated Data Notice

Data streams are simulated client-side using deterministic diurnal templates and stochastic Gaussian noise. No physical plumbing hardware or IoT meters are connected.
